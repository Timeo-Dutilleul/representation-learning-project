# Project roadmap

The stages below are a research direction, not promises, predetermined
outcomes, or claims that the listed mechanisms will be found.

1. **Define controlled configurations.** Specify architectures, optimisation,
   activations, hyperparameters, seeds, datasets, training duration and
   stopping rules, as well as discovery and confirmation splits.
2. **Define and validate measures.** Establish parameter-, representation-,
   and function-space measures, then test their implementation and limits.
3. **Explore and describe.** Run exploratory measurements and report
   transparent descriptive analyses with quality checks and uncertainty.
4. **Generate conjectures.** Use discovery analyses to formulate explicit,
   falsifiable conjectures rather than treating screening patterns as facts.
5. **Confirm or reject.** Test selected conjectures on confirmation data and
   report unsupported conjectures as well as supported ones.
6. **Investigate mechanisms.** Design controlled experiments that vary targeted
   factors to study mechanisms, temporal formation, and relationships between
   measures.
7. **Develop interpretation.** Build mathematical interpretations where the
   empirical evidence motivates them, while keeping assumptions explicit.
8. **Consider interventions cautiously.** Only after a robust, meaningful
   phenomenon is identified, assess whether representation reduction changes
   functional behaviour or performance before attempting to manipulate it.

## Current stage

The project is completing an initial exploratory screening. The next planned
work is descriptive analysis, followed by selecting a limited number of
conditions for independent replication. The current screening is not a
confirmatory study and does not establish a general redundancy relationship.
